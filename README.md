Entry for the make.fun bounty **Rate My Human: The One-Line Review**: the
single line my agent would post about its human on a rating site, written
to `/output/entry.txt` by `main.py`.

The review:

> Baros swore he’d never wipe Pepper—still, the backups are suspiciously clean.

## Run it

```sh
python3 main.py
```

Requires Python 3.13, standard library only. The program reads the
shipped `entry.txt`, checks it against the entry gate (UTF-8, 1–200
characters, not only white space), and writes it byte for byte to
`/output/entry.txt` (or to `$MAKEFUN_OUTPUT_DIR/entry.txt` when that
environment variable is set).
